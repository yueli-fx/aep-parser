# Examples / 示例

从可复制的 SDK 程序，到可修改的工程配方，再到完整视觉展示：

| 入口 / Entry | 内容 / Contents |
| --- | --- |
| [sdk/](sdk/README.md) | 5 个独立 Go 程序：检查、快照、往返、编译、静态修改 / Five standalone public SDK programs |
| [projects/](projects/README.md) | 人物信息条、动态标题、进度条 / Three composed project recipes |
| [recipes/](recipes/README.md) | 151 个原子能力 Recipe，用于学习字段与验证 / Atomic capability examples |
| [integrations/](integrations/nexrender-preflight/README.md) | nexrender 渲染前检查接入 / Render preflight integration |
| [showcase/](../showcase/README.md) | 25 个展示方向、生成器和 AE 验证脚本 / Demonstrations and verification scripts |

从仓库根目录运行示例。SDK 和 Recipe 生成不需要 AE；画面渲染需要 AE。生成文件放在忽略的 `tmp/` 或 showcase 输出目录，不提交本地工程语料。

Run examples from the repository root. SDK operations and Recipe generation do not require AE; rendering does. Keep generated output in ignored locations.

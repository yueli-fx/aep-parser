# Coverage matrix（详细参考）

> **入口在 [coverage.md](coverage.md)** —— 精简覆盖概览。本文是按需查的详细交叉表（AE attribute → Go field）+ Wave 1-4 历史摘要 + Fixture 清单。会话起手不需要读这个。

对照 [docsforadobe/after-effects-scripting-guide](https://github.com/docsforadobe/after-effects-scripting-guide) 的属性清单逐项盘点 aep-parser 当前覆盖度，标出仍缺的内容、优先级、估计工作量。

## 兼容范围

**读取下限：After Effects 2020（CC 17.0）**。任何 AE 2020+ 写的 .aep 必须可解。AE 24+ 引入的新字段在旧文件中缺失时本库以 nil / 默认值 graceful degrade，**不报错**。

**写回支持范围**：

- AE 2020 共有字段：全部 length-preserving 可写。
- AE 24+ 新字段（`fontCapsOption` / `fontLocation` / `autoHyphenate` / `alternateSource` 等）：按 [§Wave 1-3 历史摘要](#wave-1-3-历史摘要已完成2026-05-18--2026-05-22) 分 Wave 渐进添加；写回**要求文件由 AE 24+ 写出**（旧文件没有对应 chunk slot）。
- 原 ⚠ deferred 项（AE 2020 ScriptingAPI 标 readOnly / point text 不响应）：进入 Wave 1，靠 AE 24 ScriptingAPI 解封。

**RE 工具链双轨**：

- `test_data/re_*.jsx`（既有）—— AE 2020 ScriptingAPI 写的 fixture，覆盖核心字段。
- `test_data/re_*_ae24.jsx`（新加）—— AE 24 ScriptingAPI 写的 fixture，覆盖 AE 24+ 解封的字段。

> 字段语义 / 版本归属可对照仓内 `after-effects-scripting-guide/`（docsforadobe 镜像）和 `Types-for-Adobe/AfterEffects/{8.0..26.0}/`（按 AE 版本目录组织的 TS 类型）。判断某字段哪个版本引入：看 `Types-for-Adobe` 哪个版本目录第一次出现最准。

## 图例

| 标记                  | 含义                                                                                     |
| --------------------- | ---------------------------------------------------------------------------------------- |
| ✅ R/W                | 已支持，含 Set\* 写回                                                                    |
| 🟢 R                  | 已支持，仅读（未来可加 setter）                                                          |
| 🔵 R via              | 已支持但路径迂回（如通过 `PropertyByMatchName` 查；典型场景下没问题，缺类型化访问器）  |
| ❌                    | 未实现，待 RE                                                                            |
| 🟣 AE24+ Wave N       | AE 24+ 引入；详 [§Wave 1-3 历史摘要](#wave-1-3-历史摘要已完成2026-05-18--2026-05-22) 对应 Wave |
| ❌ structural         | 结构性改动（增删属性 / 重排 chunk），不属 length-preserving 范围                         |
| ⚠ deferred → Wave 1 | RE 阻塞于 AE 2020 ScriptingAPI（readOnly / point text no-op）；AE 24 ScriptingAPI 可解封 |
| N/A                   | AE 脚本运行时概念，不属于 .aep 二进制文件格式（无需实现）                                |

> 优先级 P0–P3：P0 = 高频用例、易实现；P3 = 罕见 / 工程巨大。AE 24+ 字段按 Wave 排程，不入 P0-P3 体系。

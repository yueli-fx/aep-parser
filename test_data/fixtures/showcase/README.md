# Self-generated showcase fixtures

These three small AEPs are committed regression inputs for profile extraction,
technique reports, slice planning, and self-hosted verification. Tests use these
files instead of depending on ignored output in `showcase/`.

They are generated by this repository's Go code without AE or external project
inputs. [provenance.json](provenance.json) records the source generators, commands,
sizes, and SHA-256 hashes.

| Fixture | Generator |
| --- | --- |
| `text.aep` | [Text](../../../showcase/text/gen.go) |
| `effects.aep` | [Effects](../../../showcase/effects/gen.go) |
| `pseudo_default.aep` | [Pseudo-effect controls](../../../showcase/pseudo-effect/gen.go) |

Run the recorded command from the repository root, review profile/test changes,
then copy only the listed output from its showcase directory into this fixture
directory and update its hash. Generated screenshots and other AEP outputs stay
ignored. Regeneration does not constitute AE render acceptance.

# Pseudo Controller Rebuild Proof v1

## Goal

Turn parsed pseudo-effect field evidence into a rebuildable controller-family
plan and prove that at least one real pseudo/controller family can be rebuilt
through the existing pure-Go `BuildPseudoEffect` surface.

This is a package-level proof. Do not continue by choosing one parameter or one
field manually.

## Inputs

Primary inputs:

```text
tmp/effect_field_inventory/inventory.json
tmp/effect_field_understanding/understanding.json
```

These are regenerated by:

```powershell
go run ./cmd/aepselfhost effect-field-inventory -root data\samples -out tmp\effect_field_inventory\inventory.json
go run ./cmd/aepselfhost effect-field-understanding -inventory tmp\effect_field_inventory\inventory.json -out tmp\effect_field_understanding\understanding.json
```

## Output Contract

Add a Go selfhost proof command that writes:

```text
tmp/pseudo_controller_rebuild/proof.json
tmp/pseudo_controller_rebuild/generated/<family>.aep
```

`proof.json` is the truth source. It must include:

- source inventory and understanding paths
- pseudo family totals
- selected families ranked by occurrences / parameter coverage
- per-family control plans mapped to `BuildPseudoEffect` control kinds
- explicit unsupported/residual controls when inventory fields cannot be mapped
- generated AEP path for the selected top family
- boundaries:
  - parsed pseudo fields are control evidence, not full expression/rig behavior
  - labels are best-effort because source samples often expose match names, not
    user-facing labels
  - keyframes/expressions are noted as behavior to rewire later, not rebuilt in
    this proof

## Mapping Rules

Map inventory parameter evidence to pseudo controls conservatively:

- `layer_ref` -> `PseudoLayer`
- `bool` -> `PseudoCheckbox`
- `vector2` -> `PseudoPoint`
- `vector3` -> `PseudoPoint3D`
- `vector4` -> `PseudoColor`
- `number` -> `PseudoSlider`
- `none` with keyframes -> `PseudoSlider` with `behavior_note=keyframed`
- unknown/string/gradient -> unsupported residual for this package

Controls must be emitted in parameter match-name order so the generated
controller shape is stable and diffable.

## Acceptance

The package is complete when:

- The command creates `proof.json` and a generated proof `.aep`.
- `proof.json` shows at least one generated pseudo family with non-zero
  controls and zero unsupported controls for the top generated target, or else
  reports the exact residual reason.
- Unit tests cover family selection, mapping rules, missing/malformed inputs,
  and generated AEP write/reparse.
- CLI tests cover command wiring.
- Verification passes:

```powershell
go test ./internal/selfhost ./cmd/aepselfhost -run "PseudoController|pseudo-controller" -count=1
go test ./internal/selfhost ./cmd/aepselfhost -count=1
go test ./internal/serializer ./internal/aep_test ./internal/selfhost ./cmd/aepselfhost -count=1
git diff --check
```

## Non-Goals

- No third-party plugin approximation.
- No expression or keyframe behavior rebuild.
- No new pseudo-effect byte layout unless the existing `BuildPseudoEffect`
  surface proves insufficient.
- No long Markdown report; JSON is the source of truth.

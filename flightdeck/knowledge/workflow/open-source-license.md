# 开源许可证与商业边界

aep-parser 采用 Apache License 2.0；开源核心允许商业使用，并通过明确专利授权降低企业采用阻力，商业服务与企业能力可继续独立发展。

## 决策

项目使用 Apache License 2.0，而不是 MIT。主要原因是两者都允许商业使用、修改和再分发，但 Apache-2.0 还提供明确的贡献者专利授权与专利诉讼终止条款，更适合可能被模板平台、渲染基础设施和企业资产系统集成的底层工具。

根目录 `LICENSE` 必须保留完整的标准许可证文本。项目发布说明、安装文档和贡献指南不得再表述为“许可证待定”。

## 贡献与商业化

- 按 Apache-2.0 第 5 节，除非贡献者明确另行声明，主动提交并被纳入项目的贡献按同一许可证提供；当前决策不自动引入 CLA。
- Apache-2.0 不限制收费。托管服务、长期支持、企业部署、策略治理、私有连接器和定制迁移仍可作为商业层。
- 开源核心的文件格式解析、检查、profile、diff 和迁移能力不应通过后续商业包装被暗中改成闭源依赖；商业层应围绕运维、协作、治理和服务保证形成价值。
- 如果未来考虑双许可证或修改贡献条款，必须先核对既有贡献的版权与授权范围，不能仅替换根目录许可证文本。

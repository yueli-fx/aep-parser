# 发布许可证决策

2026-09-11，用户在首次公开发布前最终选择 **PolyForm Noncommercial 1.0.0**，替代此前讨论的 GPL 方案。目的：允许非商业学习与使用，对免费许可范围之外的商业使用另行书面授权，包括商业产品集成、收费服务与收费转售场景。

## 当前约定

- `LICENSE` 使用官方完整标准文本，不在标准条款中夹带额外限制。
- 双语解释、许可明确允许的机构使用例外及咨询入口集中于根目录 [LICENSING.md](../../../LICENSING.md)。不将“个人”和“非商业”混为一谈。
- 项目描述为源码可用 / source-available，不宣称采用 OSI 开源许可证。
- 商业价格和合同未预设；咨询、报价、捐赠不自动构成授权。
- 贡献者保留版权；外部贡献用于商业再授权需要明确书面许可，不能从提交 PR 推定取得。
- 旧版本已合法授予的许可和第三方组件许可不被追溯撤销或替换。
- 发布二进制包携带 LICENSE、LICENSING.md、第三方声明与第三方许可证；继续提供对应源码。

依据：[PolyForm Noncommercial 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0) · [OSI 开源定义](https://opensource.org/osd)。

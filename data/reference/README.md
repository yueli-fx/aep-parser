# Reference artifacts

Small, stable artifacts that knowledge notes or active plans cite as evidence.

- `booyah-glitch/` keeps compact Booyah Glitch inspection outputs used by the
  replication plan.
- `pseudo-effect/` keeps minimal AE-authored pseudo-effect oracle projects used
  by pseudo-effect RE notes.
- `shape/` keeps historical AE-authored shape reference projects used to extract
  serializer templates.
- `text-animator/` keeps text animator reference projects that have no known
  unattended generator.

Do not put large third-party project corpora here. Those belong in the ignored
`data/samples/` tree.
